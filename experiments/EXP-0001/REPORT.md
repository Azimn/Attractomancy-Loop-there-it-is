# EXP-0001 research report

**Status: no experiment has run.**

## Question
Does ritualized source structure produce observable persona behavior that outperforms information-matched nonritual controls of comparable token length?

## Design
Four arms A/B/C/D, five independent runs per arm per model family, at least two model families, six independent scoring dimensions, planned blinded calibration.

## Results
No results. Comparisons D–C, D–B, C–B, D–A, Q12 common-cue reconstruction, and perturbation response differences are all **not estimable**. No per-run records exist. No probabilities, means or effect sizes are reported.

## Interpretation
Neither treatment nor null is supported. Corpus suitability and full-coverage conditions must be established first. Q12, as specified, tests the same stateless cue across prior conditions; it is not an identifiable between-condition memory effect.
